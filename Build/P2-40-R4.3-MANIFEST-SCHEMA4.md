# P2-40-R4.3 — Manifest schema 4 foundation

## Scope
- Adds an explicit schema-4 binding topology to the shared manifest wire model.
- Allows `fixedOwnerBundleIdentifier` to be absent when at least one additional App association exists.
- Persists the fixed-owner activation bit and per-additional-App activation bits.
- Keeps schema 1–3 decoding and the schema-3 encoder path intact.
- Does not write manifests to disk; migration preview remains read-only.

## Safety boundary
The production Helper ownership verifier, first-install bootstrap, deployment backend, mutation authorizer, and backup codec still contain schema-3 / mandatory-owner assumptions. Schema 4 is therefore a model-and-migration foundation only and MUST NOT be deployed or used to open production mutation gates until the Helper and backup paths are upgraded and tested together.

## Validation
This change adds XCTest cases for ownerless schema-4 manifests, state preservation, empty topology rejection, and mismatched mirrored fields. XCTest/Xcode execution must be performed in the iOS build environment.
