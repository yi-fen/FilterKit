# P1-03.2 — ElleKit version and Mach-O metadata

## Scope

Read-only implementation for the two independent version namespaces:

- Debian package version from the `Package: ellekit` stanza in dpkg `status`.
- Mach-O `LC_ID_DYLIB` current/compatibility versions from the candidate binary.

No package installation, database mutation, signing, or injection configuration changes are performed.

## Implemented

- `DpkgStatusParser` parses the ElleKit status paragraph and preserves `Version`, `Architecture`, `Maintainer`, `Origin`, and `Homepage`. Debian continuation lines are retained for multi-line fields.
- Only the exact `Status: install ok installed` state qualifies as installed package metadata.
- `MachOMetadataReader` reads thin 32/64-bit Mach-O in either byte order, extracts `LC_ID_DYLIB` install name and packed versions, and extracts `LC_UUID`.
- CPU type/subtype provide an architecture hint when the caller does not supply one.
- Fat/universal Mach-O is explicitly rejected by this phase. A caller must select a thin slice before parsing; no arbitrary first-slice selection is made.
- `ElleKitBinaryFingerprint` combines parsed metadata with an optional `ElleKitCDHashProviding` adapter. A missing CDHash remains unknown; it is not treated as a mismatch.
- `ElleKitAssessment` now carries parsed binary metadata and fingerprints by path.

## Version semantics

`packageMetadata.version` is the Debian package version, including epoch/revision when present. `binaryMetadata[*].currentVersion` and `compatibilityVersion` are Mach-O linker metadata. They are not interchangeable and no fallback copies one value into the other.

## CDHash limitation

This phase defines and wires the provider contract only. A platform-specific CDHash implementation is not included because the supported iOS/rootless/RootHide signing inspection mechanism has not yet been validated. `nil` means unavailable.

## Validation

- Swift type-check of the changed Foundation-only environment implementation: passed on Linux Swift toolchain.
- Offline parser smoke fixtures: dpkg paragraph + continuation fields and thin 64-bit Mach-O `LC_ID_DYLIB`/`LC_UUID`: passed.
- Full Xcode/iOS SDK build and on-device Mach-O/fat-slice/CDHash verification: not performed.
