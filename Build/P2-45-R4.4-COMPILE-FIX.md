## 归集诊断（5 文件，14 条：13 error + 1 warning）

### 1. `Sources/Features/Settings/ActivityHistoryView.swift`
- 18:74 warning：`??` 左侧非可选 `String`，右侧永不使用。
- 25:28 error：`if let` 解包非可选 `String`。
- 根因：`RuntimeEventLogger.ActivityRecord.activityTitle: String`、`activityDetail: String` 均为非可选（`RuntimeEventLogger.swift:37-38`），视图按 Optional 处理。
- 修复：
  - 标题改为空串回退 `eventName`：`activityTitle.isEmpty ? eventName : activityTitle`。
  - 详情改为非空判断：`if !record.activityDetail.isEmpty { Text(record.activityDetail) ... }`。

### 2. `Sources/Environment/Deployment/AppPluginActivationOperationStore.swift`
- 109:17 / 193:21 / 199:21 error：`argument 'detail' must precede argument 'traceID'`。
- 根因：`recordPluginOperation` 签名顺序为 `pluginID: String?, detail: String? = nil, traceID: String? = nil`（`RuntimeEventLogger.swift:113`），三处调用标签写成 `pluginID, traceID, detail`。
- 修复：三处对齐为 `pluginID, detail, traceID`；仅传 `traceID`、省略 `detail` 的调用点（126/132/141/152/206/213、`PluginsView.swift:803`）带默认值可省略，标签顺序合法，未改。

### 3. `Sources/Environment/Helper/Transport/DarwinPeerIdentityProvider.swift`
- 121:26 error：`cannot find 'SecTaskCreateWithAuditToken' in scope`。
- 124:39 error：`cannot find 'SecTaskCopySigningIdentifier' in scope`；124:74 `'nil' requires a contextual type`（级联）。
- 128:36 error：`cannot find 'SecTaskCopyValueForEntitlement' in scope`；129:70 `'nil' requires a contextual type`、130:68 `cannot infer contextual base ... 'regularExpression'`（级联）。
- 根因：`SecTask` 类型及上述访问器为 macOS/Catalyst-only 公开 API，公开 iPhoneOS SDK 不导出（Apple 文档平台列表无 iOS）；`import Security` 已在，符号仍不可见。
- 修复：`readCodeSigningIdentity(auditTokenWords:)` 内 SecTask 采集路径以 `#if os(macOS)` 隔离；非 macOS（iOS）分支抛 `.codeSigningIdentityUnavailable`。
  - 不据 CDHash 或 PID 推断 Bundle ID / Team ID，不伪造标识值。
  - 内核证据链不变：audit token 双读（before/after 比对）、euid/egid/pid 校验、CDHash 读取与长度/非空守卫均保留。
  - `HelperInstallerAuthenticatedServiceObserver` 门禁与 `HelperCodeSigningIdentityBindingPolicy` 比对规则未改；iOS 下增强标识证据记为不可用，属真机闭环 pending 项。

### 4. `Sources/Environment/PluginScanRegistry.swift`
- 288:55 error：`cannot convert value of type 'UUID?' to expected argument type 'String?'`。
- 根因：`attestation.pluginID` 为 `UUID?`（`HelperPluginIdentityAttestationModels.swift:33`），而 `PluginManagementPermission.evaluate(verifiedPluginID: String?)` 形参为 `String?`。
- 修复：传 `attestation.pluginID?.uuidString`。

### 5. `Sources/Features/Plugins/PluginsView.swift`（含模型 `PluginListScope.swift`）
- 871:21 error：`generic parameter 'C' could not be inferred`；871:36 `cannot convert [PluginListStatus.AppEntry] to Binding<C>`；871:46 `cannot infer key path type from context`。
- 872:76 error：`cannot call value of non-function type 'Binding<Subject>'`；872:90 `binary operator '??' cannot be applied to String? and Binding<Subject>`。
- 根因：`PluginListStatus.AppEntry` 仅遵循 `Equatable`，未遵循 `Identifiable`；显式 `id: \.bundleIdentifier` 的 ForEach 重载在当前 SDK 下根类型推断失败，回退到 `Binding` 重载，闭包元素被误判为 `Binding<AppEntry>`。
- 修复：
  - `Sources/Features/Plugins/PluginListScope.swift`：`AppEntry` 遵循 `Identifiable`，`var id: String { bundleIdentifier }`（entries 内 bundleIdentifier 已按归一化去重，id 唯一）。
  - `Sources/Features/Plugins/PluginsView.swift:871`：`ForEach(status.apps, id: \.bundleIdentifier)` 改为 `ForEach(status.apps)`，走 Identifiable 重载，与文件内 231/631 合法先例一致。
