## Logging design
### App developer logs
- `Application Support/FilterKit/Logs/runtime.jsonl`
- `Application Support/FilterKit/Logs/runtime.previous.jsonl`
- Structured event fields, bounded to 1 MiB current file plus one previous generation.
- Exported from Settings → Developer Logs.
- Sensitive keys and known absolute paths are redacted before persistence.

### User activity
- `Application Support/FilterKit/Logs/activity.jsonl`
- `Application Support/FilterKit/Logs/activity.previous.jsonl`
- Separate minimal schema; no session/trace IDs, raw attributes, Bundle IDs, CDHashes, peer credentials, or filesystem paths.
- Bounded to 256 KiB current file plus one previous generation.

### Helper security audit
- `$JBROOT/Library/FilterKit/Helper/audit.jsonl` plus `.1`–`.3` rotations.
- Root-owned, mode 0600; contains privileged security audit details and must be handled as sensitive.
- Not included in App export. Use `Build/scripts/p245_r4_3_collect_helper_audit.sh <JBROOT> <OUTPUT_DIR>` as root on the device to copy verified audit files to an output directory outside JBROOT. Collector is read-only against JBROOT.
